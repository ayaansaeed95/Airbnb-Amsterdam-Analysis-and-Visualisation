# Airbnb-Amsterdam-Analysis-and-Visualisation
This repository contains processing, analysis and visualisation of Airbnb data in Amsterdam. The dataset is from kaggle (https://www.kaggle.com/datasets/laibaanwer/airbnb-amsterdam-dataset). The repository aims to help understand Airbnb renting behaviours in Amsterdam.

The first file is the Data Processing jupyter notebook which cleans and pre-processes the data for analysis. It handles missing values and explodes lists saved as strings into proper lists with their unique elements.
